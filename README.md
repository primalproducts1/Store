# PRIMAL Store
Tienda estática con catálogo editable, carrito local y pedido prellenado por WhatsApp. Sin backend ni gestión de stock. Publicar dist como Store en GitHub Pages. En el ZIP entregado ya se llama Store.

Lee GUIA_GITHUB.md para publicar y administrar. Lee LEER_ANTES_DE_VENDER.md para completar los datos y requisitos operativos pendientes.

Pruebas del resumen y URL: node tests/pedido.test.cjs. No envían mensajes.
